## How this directory was made

1. **Before any change** was evaluated: the contract identity of `c78a6d1` from a fresh build of
   `git archive c78a6d1` (scratch directory, same toolchain).
2. **After all code changes,** the recorded run:
   ```bash
   FORK_RPC_URL=https://bsc-mainnet.public.blastapi.io CANARY_FORK_BLOCK=128812145 node --import tsx scripts/verify-all.ts
   ```
   `SLITHER` was not set: Slither is not installed on this machine and installing it was not authorized,
   so the step is `SKIPPED` and the manifest's overall result is `INCOMPLETE` (every executed step
   passed). `IDENTITY_BASELINE` was not set either, because the contracts differ from `c78a6d1` by
   design; the identities are compared separately (step 4).
3. **Copy and restore.** The runner writes into `reports/`. Its outputs were copied into `run/`
   (`reports/canary-local-rehearsal/` became `run/canary-fork/`). The tracked files in `reports/` were then
   restored to `c78a6d1` and the run's new top-level files removed, as the earlier runs did. The
   manifest's `reports/…` paths refer to run-time locations.
4. **After the run:** `contract-identity-compare.json`, `bytecode-comparison.json`,
   `historical-unchanged.json`, then `assertions.json`. Nothing in it is asserted by hand.

An earlier full run on the tree before the last change (the first-admission gas allowance in
`sdk/gas.ts`, prompted by that run's fork measurements) passed the same steps; it was discarded and the
run repeated on the final tree, which is the one recorded here.
